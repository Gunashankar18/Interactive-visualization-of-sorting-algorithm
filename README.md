# Interactive Visualization of Sorting Algorithms

## About the Project

This project demonstrates sorting algorithms through interactive visualizations. It helps students understand how sorting algorithms work step by step.

## Features

* Visual representation of sorting algorithms
* Easy-to-understand interface
* Helps students learn algorithm execution

## Technologies Used

* HTML
* CSS
* JavaScript

## Algorithms

* Bubble Sort
* Selection Sort
* Insertion Sort
* Merge Sort
* Quick Sort

## How to Run

Open the `index.html` file in a web browser.
